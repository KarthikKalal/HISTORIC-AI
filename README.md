### 🌍 Discover the World's Heritage with AI

Historic AI is an intelligent history assistant powered by **Google Gemini AI** and **Streamlit**. It helps users explore the history of civilizations, empires, monuments, rulers, battles, cultures, and historical events from around the world through natural conversations.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/Historic-AI.git
```

```bash
cd Historic-AI
```

---

## Create Virtual Environment

Windows

```bash
python -m venv venv
```

Activate

```bash
venv\Scripts\activate
```

---

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

## Configure API Key

Create a `.env` file.

```env
GEMINI_API_KEY=YOUR_API_KEY
```

---

## Run

```bash
streamlit run app.py
```

or

```bash
python -m streamlit run app.py
```
